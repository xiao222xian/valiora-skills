# Changelog

## [0.4.0] - 2026-10-30

### Added

- 叙事、履历与招募长文：图跟着故事走
- 用真实故事串起履历的叙事与招募长文默认需要正文配图，按 Kit 根目录 references/body-figures.md 的新章节执行
- 验收新增：图紧跟点名它的段落，演讲与活动图里看得到作者本人，成就与数字由原始页面截图或汇总证据图承担

## [0.3.0] - 2026-10-01

### Changed

- 招募、活动、探店、旅行和空间介绍类文章默认需要正文配图，不再“一节一张代表图”
- 读者将去的每个地点配相邻实拍；同主题 3 张以上素材做成手机可读的组图（1800px、12px 白色间距、图上不加字、最多 3 列）
- 真实产物（报告页、产品截图）用组图展示，演示数据在图注写明；可加等权重的致谢 Logo 条
- 组图同样过人脸、车牌、电话、WiFi、第三方二维码的隐私门禁，店铺身份未确认不点名

## [0.2.0] - 2026-09-12

### Added

- 区分完整存档与编辑精选，去除重复样板图注
- 新增“完整存档/实录复刻”判定：用户提供完整真实素材集合时默认全量收录，不擅自精选
- 真实素材可直接交接，不必经过 lov-illustrate 重新生成
- 同一句样板图片说明不得在每张图下重复，信息写进 alt 文本一次

## [0.1.1] - 2026-09-07

### Added

- 统一展示名为「正文图解」，保持调用 ID 与能力契约。

## 0.1.0 - 2026-09-05

- 新增正文配图判定模块：按题材判定是否需要配图，交接 `lov-illustrate` 产出，并验收图片是否承载正文证据。
