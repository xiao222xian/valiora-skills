# Changelog

## [0.7.0] - 2026-10-30

### Added

- 视频脚本改文章按故事重写；同一句话只出现一次；强调只用加粗
- 输入是视频脚本或口播稿时，不沿用一句一行、一句一图的节奏，按故事重写成连续段落
- 同一句话、同一组数字在正文只出现一次；承重句和感悟只用加粗

## [0.6.0] - 2026-09-12

### Added

- 新增实录转写模式，并加固标点、段落节奏、事实中立与第三方措辞规则
- 新增“实录转写”模式：演讲/访谈类转写稿默认最大化保留原始措辞与语序，不再默认改写成自顶向下叙事
- 章节编号/命名遇到可核实来源时必须核对原始结构，不得凭感觉重新编号
- 中文正文默认全角标点；技术性内容保留半角
- 长段落按自然停顿拆短，服务移动端阅读节奏
- 结果性事实模糊时保留中性表述，不脑补负面版本；向用户求证优先于替用户归因
- 涉及真实第三方的负面经历默认使用克制措辞，降低贬低感

## [0.5.1] - 2026-09-07

### Added

- 统一展示名为「文章写作」，保持调用 ID 与能力契约。

## 0.4.0 - 2026-08-31

- 移除重复的通用写作规则所有权，统一通过 `lov-writing-style → lov-human-writing` 完成文风与作者性处理。

## 0.3.0 - 2026-08-31

- 为研究评测类文章加入论文式章节、评分示例和可复现性门槛。
