# Changelog

## [0.5.0] - 2026-09-12

### Added

- 章节编号与命名遇到可核实来源时必须核对原始结构
- 素材自带章节编号/命名体系（PPT 章节页、原始大纲等）时，正文 H2/H3 默认原样沿用来源，不得凭感觉重新编号或命名

## [0.4.1] - 2026-09-07

### Added

- 统一展示名为「文章装帧」，保持调用 ID 与能力契约。

## 0.3.1 - 2026-09-01

- 微信正文默认隐藏 canonical H1，并将资料与引申链接降级为低对比度小字斜体资料注。

## 0.3.0 - 2026-08-31

- 校准 `4:3` 正文首图位置，并保留研究评测类论文式章节标题。
